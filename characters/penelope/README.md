# Penelope — character slot

Drop the character card here:

```
Penelope3.png   (PNG with embedded chara tEXt chunk — SillyTavern V2/V3 export)
# or
penelope.json   (raw V2/V3 JSON)
```

Then point `.env` at it:

```
CHARACTER_PATH=./characters/penelope/Penelope3.png
CHAR_LABEL=Penelope
```

Real card PNG currently lives in `~/Projects/sillytavern-telegram-bot/data/Penelope3.png`
(active bot instance). Copy it here if you want to run Penelope from this repo.
